# 段考監考教室系統 V1.13

靜態 HTML 電子白板，入口為 index.html。

線上使用：https://mikibear418.github.io/exam-classroom-system/

## V1.13 更新
- 新增紫藤、晴空、薄荷、暖杏、櫻花、岩灰六種主題，從最上方「主題配色」選擇。
- 主題套用白板與後台，立即生效並儲存在目前瀏覽器，也納入系統 JSON 備份。
- 右下角學生背景圖不透明度提高至 40%，輪廓更加清楚。
- 縮減系統導覽、學年度考試標題、年級教室名稱與日期選單區高度。
- 保留 16px 選單文字與至少 38px 的主要操作高度，增加鍵盤焦點提示。
- 男女學生插圖放在右下角，以 40% 不透明度作為背景，不攔截操作。
- 全螢幕依儲存的順序、寬度與高度比例適配五格，整頁不捲動；超出內容在各格內捲動。
- 方格寬高及字級各自保存，離開全螢幕會還原原先尺寸；不變更原有本機資料格式。
- 寬版目前考試格將時鐘與科目並排，注意事項保留雙欄，窄格自動單欄。
- 修正原始 HTML 多餘的 style 起始標籤，更新外觀設定說明與尺寸控制的朗讀標籤。
- 保留名冊、排座、出缺席、PDF / Excel / CSV 與圖片 OCR 匯入功能。

## 下載包使用
1. 解壓縮完整資料夾，保留 index.html 與 assets 的相對位置。
2. 使用 Chrome 或 Edge 開啟 index.html，或使用上方線上網址。
3. 先選日期、年段、教室，再按「全螢幕」。再次點選同一按鈕或按 Esc 可離開。
4. 一般模式按「編輯方格位置／大小」拖曳標題及右下角，或至後台「白板外觀」精確調整。

## 資料與連線
- 資料儲存於目前瀏覽器 localStorage，不會跨裝置自動同步。上線更新沿用同一網址的既有資料。
- 本機檔案與線上網址使用不同儲存空間；可透過後台備份、還原轉移資料。
- 不要將真實學生名冊、座位與出缺席資料提交到公開儲存庫。
- PDF、Excel 與圖片 OCR 沿用外部程式庫，首次使用需要網路；掃描 PDF 可能需要 OCR 並人工核對。
