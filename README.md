# 段考監考教室系統 V1.10

靜態 HTML 電子白板應用，使用 GitHub Pages 發布。

## 使用方式
- 網頁入口：`index.html`
- GitHub Pages：Settings → Pages → Deploy from a branch → main / (root)
- 使用瀏覽器 Chrome 或 Edge 開啟。

## 重要提醒
- 此版本使用瀏覽器本機儲存（localStorage），不同裝置之間**不會自動同步**。
- 不要將學生真實姓名、名冊、座位與出缺席紀錄提交到公開 GitHub 儲存庫。
- 名冊匯入及 PDF/Excel 識別可能需要載入第三方前端程式庫，建議保持網路連線。

## V1.10 更新
- 五個資訊方格可各自調整寬度與固定高度，不再互相交換寬度；其他方格只重新排列。
- 注意事項採左右雙欄，較窄的方格自動切換單欄。
- 標題區放置兩張 ImageGen 原創應考男女學生插畫，檔案位於 `assets/`。
- 若設定固定高度導致內容超出，內容會在所屬方格內捲動。設為「自動高度」則依內容延伸。
