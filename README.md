## 下載包使用
1. 解壓縮完整資料夾，保留 index.html 與 assets 的相對位置。
2. 使用 Chrome 或 Edge 開啟 index.html，或使用上方線上網址。
3. 先選日期、年段、教室，再按「全螢幕」。再次點選同一按鈕或按 Esc 可離開。
4. 一般模式按「編輯方格位置／大小」拖曳標題及右下角，或至後台「白板外觀」精確調整。

## 資料與連線
- 正式入口使用 Google 教師登入與 Supabase 雲端同步，僅可存取已授權班級。
- 本機版入口： https://mikibear418.github.io/exam-classroom-system/?cloud=local ，資料儲存於此瀏覽器，沿用原本本機資料。
- 本機檔案與線上網址使用不同儲存空間；可透過後台備份、還原轉移資料。
- 不要將真實學生名冊、座位與出缺席資料提交到公開儲存庫。
- PDF、Excel 與圖片 OCR 沿用外部程式庫，首次使用需要網路；掃描 PDF 可能需要 OCR 並人工核對。

## V1.16 Google 教師雲端模式（已啟用）

2026-11-23 啟用 `cloud/config.js` 的 `enabled:true`，保留 Google 登入；Email／密碼登入未開放。既有兩位教師的跨帳號 Realtime 自動更新已由使用者確認。

- 授權由資料庫 `classroom_members` 與 RLS 控制，Google 登入本身不會授予任意班級權限。
- 班級成員只能由學校管理者在受保護的管理環境設定。
- **原本本機資料不會自動遷移。** 在原裝置、原瀏覽器開啟「本機版／備份」，下載「儲存本班版本」JSON；再由有編輯權限的教師登入同名雲端班級，使用「載入班級版本」並確認取代內容。
- 完整本機 JSON 備份只在本機版還原；雲端匯出限目前班級。
- 雲端寫入不會覆寫原有 localStorage。本機版顯示的資料與雲端各自獨立。
- 雲端套件或連線失敗時維持啟動畫面／登入畫面，提供明確的本機備援入口。
- 約 850ms 後儲存；版本衝突停止覆蓋。先下載目前班級 JSON，再使用「同步」重新載入。
- 公開設定僅含 publishable key；禁止提交 secret、service_role 金鑰、教師密碼或真實學生名冊。

更多設定見 `cloud/SETUP.md` 與 `cloud/GOOGLE_OAUTH.md`。
